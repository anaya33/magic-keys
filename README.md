# Magic Keys

Magic Keys is a piano. Press any key and it plays real songs.

**Play it:** https://anaya33.github.io/magic-keys/

## Modes

**Magic.** Press any key and the next note or chord of the song plays on the right
piano keys. You set the pace. **Autoplay** plays the whole song for you.

**Learn.** The next key to press lights up, with its note name and keyboard
shortcut. The song moves on when you press the right key. A wrong key makes the
right one wiggle. Practise the right hand (the left hand is played for you) or
both hands.

**Free play.** A normal piano. Play with the mouse, touch, your computer keyboard
(`Z`–`/` and `Q`–`]`, `Space` for the pedal) or a MIDI keyboard.

**Listen.** Play or hum something into the microphone. It's turned into notes
and saved as a song you can play in the other modes.

**Songs.** Für Elise, Moonlight Sonata (1st movement), Prelude in C Major,
Clair de Lune (opening) and Gymnopédie No. 1 (opening). You can also upload your
own sheet music as MusicXML.

**Phones.** Hold your phone sideways for the full piano. Held upright, Magic and
Learn turn into piano tiles that keep you on the beat.

## Run it

```bash
npm install
npm run dev
```
