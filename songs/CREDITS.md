# Song credits

Every piece here is a public-domain composition. The MusicXML encodings come from
[PDMX](https://zenodo.org/records/15571083) (via the [pdmx-piano](https://github.com/PLAZMAMA/pdmx-piano)
selection), where each uploader released their encoding on MuseScore.com under CC0.
Titles and credits were cleaned up for Magic Keys; the notes are unchanged except where noted.

| File | Piece | Encoding | Notes |
| --- | --- | --- | --- |
| `fur-elise.musicxml` | Beethoven, Für Elise, WoO 59 | [Lochnes_Benedict](https://musescore.com/user/27431759/scores/5036717) | Complete |
| `moonlight-sonata.musicxml` | Beethoven, Piano Sonata No. 14, Op. 27 No. 2, I | [Timbo101](https://musescore.com/user/7408361/scores/5300478) | Complete first movement |
| `bach-prelude-in-c.musicxml` | Bach, Prelude in C major, BWV 846 | [Abelio](https://musescore.com/user/19750301/scores/3872551) | Complete (Czerny edition) |
| `clair-de-lune.musicxml` | Debussy, Clair de Lune | PDMX id `QmeMaKsVzm3njZN9ZSYwN7E9XQGC7fyyBsGMm1NnEt7H9m` | Opening, bars 1–30 |
| `gymnopedie-1.musicxml` | Satie, Gymnopédie No. 1 | [Freb](https://musescore.com/freb/scores/6360221) | Bars 1–12; the source was a harp arrangement in C, restored here to Satie's original D major (these bars match the original note for note) |

To add a song, drop any `.musicxml` file into this folder. It shows up in the library automatically.
